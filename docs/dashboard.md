# 管理ダッシュボード操作マニュアル(Lite版)

Web管理ダッシュボード(`--admin` ポート)は、依存ゼロの単一HTMLで動く監視・操作画面です。
本書はパネル単位の使い方を説明します。全体像・クイックスタートは [README.md](../README.md)、
防御一覧・設定キーは [defenses.md](defenses.md) / [options.md](options.md) を参照してください。

> 本エディションに含まれない機能(PoWチャレンジ・DNSフィルタ・SIEM転送・自己完全性監視・
> watchdog自動再起動・GeoIP・ステルス運用・横展開デコイ・脅威インテリジェンス・分散BAN同期・
> 商用ライセンス管理・ハニーポット等)は、フル版(DuckNet)にのみ含まれます。詳細はダッシュボード
> 右上の ❓(ヘルプ)、または [README.md](../README.md) 冒頭の一覧を参照してください。

## ログイン

設定した管理トークン、または対話コンソールでの起動時に表示される自動生成トークンで認証します。ブラウザで
`http://127.0.0.1:8081/` を開き、表示された入力欄にトークンを入れてください。
設定済みのトークンは起動時に再表示しません。Docker・systemd・出力リダイレクト等の
非対話運用では、自動生成値もログに出さず、既存の `DUCKNET_ADMIN_TOKEN` を設定して
起動する案内を表示します。未設定のまま非対話で起動した場合は、設定して再起動してください。
ブラウザはトークンを開いているページのメモリだけに保持します。API 要求ごとに時刻・nonce・
メソッド・パス・本文ハッシュをトークンで HMAC 署名し、応答の状態コードと実本文も検証します。
生のトークンは要求ヘッダや Cookie へ送りません。ブラウザでの操作には WebCrypto が使える
localhost または HTTPS が必要です。
画面内のマスク入力でロックを解除します。パスワードマネージャの入力補助に対応し、認証失敗時は
ページを再読み込みせず再入力できます。本体の再起動後も起動IDを取得し直して署名を検証します。
右上の**ロック**は下書きを残したまま認証情報を消去し、操作を停止します。
再読み込みや新しいタブでは入力し直します。トークンや派生鍵をブラウザ保存領域へ記録しません。
旧版の管理 Cookie は使わず、画面を開くと失効させます。
旧版の `?token=` URL は値を採用せず画面表示時に消去するため、管理 URL だけを開いて入力してください。
API クライアントは `Authorization: Bearer <token>` または `X-Token` ヘッダを使えます。
ブラウザの再送防止記録は全画面で最大8192件を共有し、不正なMACは登録しません。
保持期限と署名の許容時間が両方過ぎた記録を回収し、回収した署名の時刻も拒否境界として保持します。
上限時はブラウザ要求を拒否しますが、ヘッダートークンを使うAPIクライアントの認証は継続します。
サーバ時刻の大幅な巻戻し後はブラウザ認証が安全側で拒否を続ける場合があります。
時刻を整え、管理サーバの再起動と画面の再読込で認証インスタンスを更新してください。
管理画面・API・設定ダウンロード・エラー応答には `Cache-Control: no-store`、
`Pragma: no-cache`、`Expires: 0` を付け、状態や操作履歴のキャッシュ保存を禁止します。
前段プロキシでもこれらのヘッダーを維持し、管理応答を共有キャッシュから再配信しないでください。
署名済み応答は16MiBまで読み取り、GETは10秒、変更要求は30秒の総期限で中止します。
起動IDの再取得は2MiB・8秒までです。上限超過や検証失敗は成功表示にせず、接続を回収します。
管理ポートを別プロセスが待受け直しても、その相手へ生トークンを送らず、検証できない応答は
表示しません。ただし未使用の署名済み要求を同じメソッド・パス・本文で中継される可能性や、
偽画面に人がトークンを入力する危険は残ります。管理ポートは信頼できるローカル環境で
運用し、HTTP の loopback 待受だけで他のローカルプロセスから完全に隔離できるとは扱わないでください。
トークンは環境変数 `DUCKNET_ADMIN_TOKEN`(またはゲートウェイの起動オプション `--token`)で
固定指定も可能です。コマンドラインの引数は同じ PC の他のユーザーから読めるので、環境変数を
推奨します(`app.env` に書けばトレイが本体を起動するときに同じトークンを使います。
詳細は `python -m dataplane --help`)。

## ヘッダーバー

- **接続中 / 接続不可**: ダッシュボードとゲートウェイ間の疎通状態(2秒毎にポーリング)。
- 子ワーカーが実際に稼働している場合は、黄色の「接続中・親ワーカーのみ」を表示します。
  カードとイベントは親ワーカーの値で、全ワーカーの合計ではありません。`/api/state` も
  `telemetry_complete: false`、`telemetry_scope: "per-worker"` を返し、集計値だけを返す
  `/api/metrics` や `/api/shield/events` 等は 503 で拒否します。単一ワーカーへ降格した後は
  全体の値を再び表示します。
  集計できない各パネルにも理由を表示し、子ワーカー停止を伴う操作は送信前に確認します。
- **❓(ヘルプ)**: 使い方・できること・フル版との違いを画面内に表示します。
- **EN / 日本語**: 表示言語の切替(即時反映・選択は保存されます)。
- **☀️/🌙(テーマ)**: ライト/ダーク切替(既定はOSのテーマに追随)。

## 上部コントロール

- **ファイアウォール** / **DDoS / 侵入防御**: 各防御レイヤーの ON/OFF。
- **遮断・監査モード**: シールドの検知を遮断に使うか、監査記録だけにするかを選択します。
  出口DLPも全体の監査モードに従います。HTTP構文や状態検証の失敗は監査中も拒否される場合があります。
- **🌍 グローバル遮断 / 解除**: `public` ゾーン全体を一括で遮断/解除する非常ボタン。

## 実行時の防御設定

折りたたみパネルを開くと、稼働中に変更できるNetShieldの113設定を14分類で表示します。設定名・機能で検索でき、
真偽値、選択肢、数値、文字列を型に応じて編集し、配列はタグ、辞書やパス制限は行の追加・削除で
編集します。説明、既定値、許容範囲、入力例も表示します。上級者向けのJSON編集は折りたたみ内に残し、
不正なJSONや未確定の入力を自動更新で消しません。日本語・英語の切替に対応しています。

待受・backend・ワーカー・状態保存先などの起動設定は、このパネルの対象外です。
[起動引数・環境変数](options.md)で指定し、変更には**DuckNetアプリの停止・起動**が必要です。
Windows自体の再起動は不要です。本文退避には、設定によらない固定の安全上限があります。

入力中の変更は自動更新では消えず、**変更を保存**で変更した項目だけを一括適用します。入力不正や
保存失敗では成功扱いにせず、入力内容を残します。別の管理画面やAPIが先に設定を変更した場合は
競合として保存を拒否します。**変更を破棄して再読込**で最新設定を読み直し、内容を確認して再編集してください。
接続・認証の状態を検証できない間は設定操作を無効にします。
追従する保存バーで未保存件数を確認し、**変更内容を比較**で変更前後を見てから保存できます。
上段の個別カードは即適用、この詳細パネルは保存時に適用されます。個別カードで同じ設定が変更された場合も
詳細パネルの下書きを黙って上書きせず、保存時に競合を通知します。

シールドOFF、機能ごとのON/OFF、全体の監査モードは別の設定です。DLP欄は設定値だけでなく実効状態を
表示します。私有パスの許可表、信頼proxy、本文・GraphQLの上限、送出クォータなどは説明と配備条件を
確認して設定してください。既存の保存済み設定や既定の防御値は、画面を開くだけでは変更しません。

## トレイ表示(Windows)

トレイ常駐(`python -m dataplane tray` / `DuckNet-Tray.bat`)は、**DDoS / 侵入防御** の ON/OFF を
アイコンとツールチップで示します(5秒ごとに既存の `/api/state` のHMAC応答を検証し、変わった時だけ更新)。
ダッシュボードを開かなくても、止まった防御に気づけるようにするためです。切替そのものはこの画面で行います
(トレイには切替を持たせていません)。

| 表示 | アイコン | ツールチップ |
| --- | --- | --- |
| 防御 ON | 通常 | `<名前> — 防御 ON / Protection ON` |
| 監査モード(記録のみ) | 淡色(灰色) | `<名前> — 防御 ON(監査モード: 検知は記録のみ)/ Protection ON (audit: record only)` |
| 防御 OFF | 淡色(灰色) | `<名前> — 防御 OFF(ダッシュボードで ON にできます)/ Protection OFF` |
| 本体に届かない | 淡色(灰色) | `<名前> — ゲートウェイに接続できません / Gateway unreachable` |
| 認証できない | 淡色(灰色) | `<名前> — 状態を確認できません(管理トークン未確認)/ Status unknown (admin token unverified)` |

- `<名前>` は製品名(`DUCKNET_COVER` を設定していればその偽装名)。
- 起動直後は淡色の「状態未確認」から始め、起動子の署名付き状態を確認してから更新します。
  子の自動起動はHTTPの数値loopback宛だけです。HTTPS・名前宛・外部宛には、HTTPの子を誤って起動しません。
  トレイの異常終了や停止未完了は終了コード1で報告し、自分で起動した子の回収を試みます。
- **監査モード**(`mode=audit`)は、署名・ポリシーの検知を記録のみとします(出口 DLP の `block` も
  記録のみ)。HTTP の曖昧な構文や検査できない GraphQL 本文など、解釈を安全に確定できない要求は引き続き拒否します。ダッシュボードの「DDoS / 侵入防御」は ON のままですが、試験のために切り替えたまま戻し忘れても
  気づけるよう、トレイでは ON と別の表示にし、アイコンも淡色にしています。遮断に戻すには `mode` を `enforce`
  にします(`POST /api/shield/config {"mode": "enforce"}`、または `--config` / `DUCKNET_CONFIG` の設定ファイル。
  キーは [defenses.md](defenses.md))。シールド自体が OFF の間は、監査モードかどうかに関わらず「防御 OFF」です。
- トレイが自分で起動した子本体には、管理トークンとは別の内部鍵を渡し、
  毎回新しい nonce と防御状態を結んだ HMAC 応答を既存の `/api/state` の 401 で確認します。
  状態ポーリングで管理トークンは送信しません。
  単なる `401 token required` 応答は他のプロセスにも模倣できるため、本人確認には使いません。
- 本体を別に起動している場合(`run.bat` やサービス)も、数値loopbackの管理URLと設定済みトークンがあれば、
  公開された起動IDからHMAC要求を作り、応答MACを検証して状態を表示します。生トークンを送信せず、
  リダイレクトや検証不能な相手を拒否します。未設定・不一致時は状態未確認のまま操作を制限します。
- トレイ自身が起動した本体については、「ダッシュボードを開く」で HMAC 応答を確認し、
  トークンを含まない管理 URL を開きます。初回表示時は管理トークンを入力してください。
  必要なら確認ダイアログでコピーを明示的に選べます。トークンを平文のダイアログには表示しません。
  コピーした内容と更新番号が変わっていない場合に限り、約30秒後または終了時に消去を試みます。
  他のアプリが使用中なら消去できない場合があり、OSの履歴や他アプリが読んだ複製までは消せません。
  右クリックメニューには、操作できない状態表示と確認可能なBAN件数を表示します。集計不完全時は件数未確認です。
  本体が停止した場合や管理 URL が数値 loopback でない場合は確認を促すメッセージを出します。
- 淡色アイコンは `DuckNet-off.ico`。`DUCKNET_ICON_DIR` で独自アイコンに差し替えている場合は、同じ場所に
  `DuckNet-off.ico` も置いてください(無ければ OFF の間も通常アイコンのままで、状態はツールチップで分かります)。
- Explorer が再起動すると(異常終了・Windows の更新・タスクマネージャーからの再起動)通知領域は作り直されます。
  トレイは Windows が送る `TaskbarCreated` を受けてアイコンを追加し直すので、トレイを起動し直す必要は
  ありません。出すのはその時点の最新の表示(防御 OFF なら淡色アイコンと OFF のツールチップ)です。ログオン直後
  など Explorer より先にトレイが起動してアイコンを出せなかった場合も、Explorer の準備ができた時点で出ます。
  管理者として起動している場合に備え、このメッセージだけは通常権限の Explorer からも受け取ります。

## 概況

確認ダイアログは同時に1件だけ表示します。Tab/Shift+Tabはダイアログ内を移動し、
キャンセル上のEnterやEscapeでは操作を実行しません。ヘルプもTab移動が内側に留まり、
閉じると元の要素へフォーカスを戻します。更新で元の行が消えた場合はヘルプボタンへ戻します。

設定の送信中は対象の操作を無効にし、自動更新がその値を上書きしないようにします。
接続上限などの整数設定欄では、空欄・小数・負数・正確に表せない巨大値を送信しません。
接続上限を無制限にする場合は、明示的に
`0` を入力してください。一括操作は開始時に選んだ対象だけへ実行し、確認待ち中に新しく
届いた行へ対象を広げません。永続BANの残り時間は「無期限」と表示します。

狭い画面ではヘッダとパネルを折り返し、長いIPv6アドレスを含む表はパネル内で横に
スクロールします。ページ全体を横へ動かして操作ボタンを探す必要はありません。

- **リアルタイム通信**: req/s・block/s の折れ線。1分/5分/10分(全保持)で切替。保持は最大600点です。
  ホバーや矢印キーで、その時刻の値を確認できます。
- **ネットワーク図**: 中心=本機、内→外に loopback/private/public。ノードをクリックすると
  そのIPの一時BAN・解除を切り替えます。恒久ACLはアクセスルールの一覧から管理します。

## 脅威モニタリング

- **攻撃イベント**: 直近100件を取得し、IP・種別・理由・シグネチャで絞り込みます。行を開くと
  スコア、監査時の予定動作などを確認でき、CSV/JSONにも詳細を保持します。
- **BAN中のIP**: 自動/手動BANの一覧。残り時間・スコアでソート、選択解除/全解除、手動BANも可能。
- **上位送信元(脅威スコア順)**: スコアの高い送信元IPのランキング。
- **APT級の兆候**: 低速持続・規則的ビーコン・累積型など、単発では検知しづらい兆候の集計。
  上位送信元とAPTの表から、既存のBAN・解除やイベントの絞り込みへ進めます。
- **シグネチャ別ヒット**: どのシグネチャが何回ヒットしたか。
- **トラフィック構成(ゾーン / アクション)**: public/private等のゾーン別・allow/block等の
  アクション別の内訳。
- **HTTPメソッド別**: メソッド別の集計。

CSVは表計算ソフトでの閲覧向けです。数式と解釈され得る先頭文字を持つ文字列には、
引用したセル内でタブを補います。このタブはデータの一部になるため、元の値を正確に
再利用する場合はJSONを選んでください。表計算ソフトで保存し直した後まで、すべての
ソフト・読み込み方法で数式解釈を防ぐ保証はありません。

## WAF / 検知設定

- **WAF 追加シグネチャ(任意・高FP)**: 既定OFFの高感度シグネチャ群。誤検知許容な環境のみ点灯。
- **カスタムシグネチャ**: 独自の正規表現シグネチャを追加。追加前に安全性(ReDoS)検査つきの
  ドライラン試験ができます。照合は検知と同じく正規化(URL/実体参照の復号・小文字化)後の値に
  対して大文字小文字を区別せず行います(`%41` などの符号化された字面は当たらないので復号後の文字で
  書く)。同じ名前で追加すると置き換え(編集)、最大 256 件。weight 0 は記録のみ(加点しない)。
  weight は 0〜1000 で、1000 を超える値は 1000 として扱います(1 回の一致で BAN 閾値を大きく超える。
  以前の版で保存した weight 5000 などの規則も有効のまま)。NaN・無限大・負の値は受け付けません。
- **パス別レート制限**: 特定パスに個別のレート上限を設定。
- **レート/メソッド/分散(運用)**: グローバル接続上限・per-IP上限・メソッド別制御等の運用設定。
- **出口DLP(秘密漏洩)**: 応答(ヘッダと本文先頭)からの秘密情報(APIキー等)漏洩を検知。
  `audit` は記録のみ、`block` はその応答を送らず切断します(伏字化して送り続ける機能はありません)。
- **詳細防御(評価)**: opt-inの高度防御設定。

## アクセス制御・申立

- **アクセスルール**: 明示ルール(allow/deny)を一覧・検索・削除できます。
  loopback/private/publicそれぞれのゾーンポリシーもallow/deny/promptから変更できます。
- **解除リクエスト(異議申立)**: BANされたクライアントからの異議申立を確認・承認/却下。
- **承認待ち接続(ファイアウォール)**: ゾーンポリシーが「承認待ち」の未知接続をここで承認/拒否。

## 欺瞞

- **デセプション(MTD)**: 欺瞞的防御(モーヴィングターゲット等)の状態。

## 詳細分析

- **詳細分析**: アクション別の件数・ゾーン別・上位シグネチャ・イベント種別・BAN 中の IP 数を見出し付きで
  表示します。ヘッダの「接続不可」「認証エラー」にポインタを当てると、次にすること(ゲートウェイが起動して
  いるか確認する、ページを再読み込みする等)が出ます。
- **変更履歴(監査ログ)**: 設定変更・BAN操作等の監査証跡。差分表示・一部操作は取消(revert)可能。
  自由文字列・シグネチャのパターン等は機密を複製しないよう秘匿します。秘匿した値を含む履歴は
  「元に戻す」を出しません。通常の真偽値・数値・固定選択値の単独変更は従来どおり戻せます。
  旧履歴もAPIで返す際に秘匿し、保存済みの監査ファイル自体は書き換えません。
