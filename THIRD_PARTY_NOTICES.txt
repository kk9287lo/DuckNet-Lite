DuckNet L7 Security — 第三者ソフトウェア表示 (Third-Party Notices)
================================================================================
最終更新: 2026-06-26 / 対象バージョン: 1.0.0

本製品は「外部依存ゼロ(Python 標準ライブラリのみで動作)」を設計方針としています。
そのため、配布物に **同梱している第三者コードはありません**。本書は、製品の実行に
必要な実行環境、および任意機能を有効化した場合にのみ追加される第三者コンポーネントを
透明性のために明示するものです。

--------------------------------------------------------------------------------
1. 実行環境(同梱せず・利用者が用意)
--------------------------------------------------------------------------------
- Python (CPython) 3.10 以降
    ライセンス: Python Software Foundation License (PSF)
    入手元   : https://www.python.org/
    位置づけ : 本製品は Python 標準ライブラリ(asyncio, http.server, hmac, hashlib,
               json, socket, ssl 等)のみを用いて動作します。標準ライブラリは
               Python 配布物の一部であり、本製品には同梱しません。

--------------------------------------------------------------------------------
2. 同梱している第一者(自作)コンポーネント ※第三者ではない(参考表示)
--------------------------------------------------------------------------------
- Ed25519 署名(dataplane/enterprise/ed25519.py)
    本製品の純 Python 実装(自作)。第三者の暗号ライブラリ(例: cryptography, PyNaCl)
    には依存していません。RFC 8032 のテストベクトルで検証済み。
- 防御コア(dataplane/engine/ 配下の vendored サブセット)
    本製品の一部として同梱する自作コード(app_firewall / pipeline / proxy 等)。
    第三者コードではありません。

--------------------------------------------------------------------------------
